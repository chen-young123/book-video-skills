# Book Video Workflow

把模糊创意推进为可审核、可制作、可交付的短视频方案。让使用者掌握观点和审美决策，Codex 负责研究整理、流程编排和可重复检查。

## 适用范围

- 从主题或受众偏好开始策划短视频。
- 将指定书籍转化为原创口播和视听方案。
- 审查已有文案、字幕、旁白、画面或成片。
- 组织多步骤制作、失败恢复和交付复盘。

## 工作方式

1. 明确目标受众、主题、平台、画幅、时长和期望情绪；信息不足时只追问会改变成片方向的问题。
2. 核验书名、作者、版本和关键事实。把来源用于理解与校验，不复刻书籍正文、完整评论或他人的独特表达。
3. 先形成一版完整原创口播，再检查开头吸引力、论述连贯性、语言自然度、时长和结尾余味。
4. 获得文案确认后，再设计镜头、画面提示、旁白、字幕和声音方案，避免在文本仍变化时浪费媒体制作。
5. 将制作拆为可验证步骤；每一步记录输入、输出与依赖。失败时保留最近有效结果，只重试最小失败步骤。
6. 交付前检查事实、版权、字幕准确性、音画同步、画面裁切、响度、时长和目标平台适配。

## 决策节点

- **选题确认**：方向会决定后续研究与表达时请求确认。
- **文案确认**：完整口播通过后才进入媒体制作。
- **成片确认**：展示可直接查看的预览，并说明仍存在的质量取舍。
- **发布确认**：只有使用者能够决定素材授权、最终音乐和实际发布。

不要把每个确定性步骤都变成一次询问。事实不明、权限不足、授权不清或选择会显著改变结果时再暂停。

## 输出要求

- 文案应能直接朗读，并与预计时长相匹配。
- 画面方案说明每段画面服务的情绪或信息，不堆砌无关镜头。
- 字幕以已确认文案为文本真源；语音识别只辅助估计时间。
- 成片或预览完成后，直接向使用者展示可访问的结果，并附简短质检结论。
- 复盘只记录能够迁移到下次制作的规律、失败原因和改进动作。
